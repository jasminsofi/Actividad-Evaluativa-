* **Caso elegido (Práctica):** Ficha de mascota para una veterinaria.
* **Cómo probar el componente:** 
  1. Clona este repositorio o descarga los archivos.
  2. Abre el archivo `index.html` en cualquier navegador web moderno (se recomienda usar un servidor local como Live Server en VS Code).
  3. Visualiza las 3 instancias de fichas de mascotas cargadas con datos distintos y un slot personalizado.
* **Declaración de uso de IA:** Se empleó inteligencia artificial como herramienta de apoyo y consulta conceptual para estructurar la documentación de investigación y validar la sintaxis correcta de los Custom Elements y Shadow DOM, adaptando y comprendiendo todo el código con nuestras propias palabras.
